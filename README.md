# Skudi Tech — Corporate Website

A responsive, static corporate website with Home, About Us, Catalog, Services, Support and Contact sections.

## Preview
Open `index.html` in a browser. Google Fonts requires internet; system fonts are used as fallback.

## Deploy
Upload the contents of this folder to the `skuditech-website` GitHub repository. Configure your hosting service separately. This ZIP has **not** been uploaded or deployed.

## Before publishing
- Confirm that `contact@skuditech.com` exists, or replace the placeholder email in `index.html`.
- Review service descriptions and legal/business claims for accuracy.
- Replace the stylized text logo with the approved official Skudi Tech logo, if desired.
- Add your privacy policy and legal notices as applicable before collecting visitor data.

## Confidentiality
This public-facing website intentionally does **not** mention Worksite IQ, Worksite Radar, Contractor Pro, or any proprietary Asterisk communications platform. No private code or internal architecture is included.

## Files
- `index.html`: content and page structure
- `styles.css`: branding and responsive layout
- `script.js`: mobile navigation and dynamic copyright year

No build system or third-party JavaScript dependencies required.
